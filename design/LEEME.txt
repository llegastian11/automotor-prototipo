Cómo abrir
- Abre index.html con Chrome, Safari, Edge o Firefox.
- El prototipo es visual: varias interacciones son demostrativas.
- Para visualizar las fotografías y tipografías externas se requiere conexión a internet.

Configuración pendiente
- Logo definitivo: assets/js/config.js → brand.logoBase64
- WhatsApp: assets/js/config.js → contact.whatsapp (solo números con código de país)
- Correo: assets/js/config.js → contact.email
- Redes sociales: assets/js/config.js → socialLinks
- Métricas reales: assets/js/config.js → metrics o conexión con API
- Google Login: requiere un proveedor OAuth seguro; no debe agregarse client_secret al frontend.

Arquitectura
- assets/css/plaquealo.css: sistema visual y responsive.
- assets/js/config.js: marca, contacto y enlaces centralizados.
- assets/js/data.js: contenido y datos demo identificados.
- assets/js/services.js: abstracciones para catálogo vehicular y autenticación.
- assets/js/app.js: componentes, navegación e interacciones.
